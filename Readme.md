# Apex Os

## **Description**

This is an app os which has currently **very limited functionality**.

**This also takes time to open as its getting real time so wait for some time**.

## **Apps**

Notepad:- you can write text in it and and save it with ctrl+s or in built save button.

**But this has no text scrolling and when you move window text may glitch out and if you write long text it will go out of window**.

## **Features**

* Icon moving.
* Window moving.
* Notepad.
* Time.
* date.
* Time and date can also be moved with **wasd for date** and **arrow keys for time**.

### Pass this for us date formating **month day year**.
```
 -i-am-us
```
Without it its **day month year**.

## **Steps to install**

* Download appimage.
```
wget "https://github.com/SREEKEDHARNATH/Apex-Os/releases/download/v1.0/p" && wget "https://github.com/SREEKEDHARNATH/Apex-Os/releases/download/v1.0/assets.zip"
```
* unzip
```
unzip assets.zip
```
* make it executable.
```
chmod +x p
```
* run it.
```
./p
```

## Clean up
```
rm -rf assets
rm assets.zip
rm p
rm config.txt
```
**Optional**
```
rm save.txt
```
